## 写作与维护

Markdown 是内容源，GitHub 保存权威版本，Obsidian 可作为本地编辑器，Quartz 生成网站。

使用 Obsidian 时，将 `content/` 打开为 Vault。无需安装社区插件。正文使用相对 Markdown 链接；请参阅[编写规范](content/writing/editorial-guide.md)和[贡献说明](CONTRIBUTING.md)。

站点构建、发布与日常维护方法见 [MAINTENANCE.md](MAINTENANCE.md)。
